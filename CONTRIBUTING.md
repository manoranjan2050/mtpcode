# Contributing

This is the personal developer platform for Manoranjan Das (MTPCode). It is primarily maintained by the owner.

## Workflow

1. Fork/branch from `master`.
2. Keep changes scoped to one phase/module at a time (see [TODO.md](TODO.md)).
3. Follow the conventions in [CLAUDE.md](CLAUDE.md) — data-driven content via `/data` JSON, partials via `/components`, Tailwind palette only.
4. Run `npm run build` before submitting changes to confirm the Vite build passes.
5. Open a pull request describing what changed and why.

## Reporting issues

Open a GitHub issue with steps to reproduce, expected vs actual behavior, and screenshots where relevant.
