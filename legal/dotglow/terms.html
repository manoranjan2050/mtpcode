The service

DotGlow sets up and controls DIY LED matrix clocks built with an ESP32 / ESP32-S3 board and a MAX7219 display, updates their firmware over Bluetooth, and can install firmware on new ESP32, ESP32-S3 and ESP8266 boards over USB. It also contains a setup guide and a demo mode.

DIY hardware

You build, wire and power the clock yourself. Follow the setup guide, use a proper 5 V supply and take normal care with electronics. Installing firmware

Install firmware erases the connected board and writes new firmware to it. Only use it on boards you own. Keep the board connected until the installation finishes. Firmware is provided as is.
