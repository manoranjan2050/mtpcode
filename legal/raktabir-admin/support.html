Need help with Raktabir Admin?

Contact

Email mtpcode.in@gmail.com. This app is for Federation volunteers, so please also ask your camp coordinator.

Common questions

  • How do volunteers get a login? The administrator adds each volunteer's email and password in the Federation's cloud dashboard.
  • Sync says "No internet". The app keeps working offline and syncs when the network returns.
  • How do I make a backup? Settings > Backup & Restore > Create backup & share. Save the file somewhere safe.
