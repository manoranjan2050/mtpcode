Tickglint Web Flasher

Install the Tickglint smart clock firmware on your ESP32-S3 board straight from the browser. Nothing to download or install.

This browser can't flash boards. Open this page in Google Chrome or Microsoft Edge on a Windows, Mac, Linux or Chromebook computer. Firefox, Safari and phone browsers don't support it. On an Android phone, use the Tickglint app instead (Install firmware over USB-OTG).

ESP32-S3Tickglint smart clock

ESP32-S3-DevKitC-1 and compatible S3 boards. Alarms, timers, sun and moon, festivals, set up with the Android app.
Use Chrome or Edge on a computer. This page must be opened with https://. Installing erases the board's old firmware and settings.

How it works

  1. Plug the board into the computer with a USB data cable (some cables only charge). Disconnect the LCD while flashing.
  2. Press Install, pick the board's port in the list (named USB JTAG/serial, CH340 or CP210x) and press Connect.
  3. Choose Install again. It takes about a minute: don't unplug the board until it says it's done.
  4. Connect the 12864 LCD, power the board, open the Tickglint app and pair with the PIN shown on the LCD.

Problems?

No port in the list, or the board isn't found
  • Use a USB data cable and another USB port.
  • Boards with a CH340 or CP210x chip may need their USB driver (search for "CH340 driver" / "CP210x driver").
  • Hold the BOOT button while you plug the board in, then try again.
"Failed to initialize" or it stops half way
  • Take every wire off the board and use a short, thick cable.
  • Hold BOOT, press RESET once, release BOOT, then press Install.
  • Close other programs that use the port (Arduino IDE, PlatformIO monitor).
Is it safe? What does it install?
  • The firmware file is on this website (manifest) and is built from the Tickglint firmware project. Flashing happens in your browser; nothing is uploaded.
